# 蓄力与发射音效

## 当前有效方案（用户最终纠正取消行为）

采用用户选定的 C 连续拉伸作为蓄力、A 作为发射。取消时不播放任何附加声音，仅将正在播放的蓄力声用约 40ms 短淡出停止，避免截断杂音。**取消不倒放、不回弹、不触发发射声。** 当前离线候选为 assets/audio/gesture-selected-ac-v4/，保留 v3 连续蓄力本体。下方倒放/回弹设计仅为历史记录，已被此决定覆盖。用户已授权接入，运行时实现见下节。

## 2026-09-10 已接入游戏

使用 `public/audio/charge.wav` 与 `launch.wav`（来自 v4）。蓄力仅在本地明确手势且力度增加时播放：从连续 C 素材按力度取 220ms 窗口，每 110ms 最多启动一段并交叉淡化；超过 90ms 没有增加力度、减力或取消时，用 40ms 淡出停止。静止瞄准、仅改方向和发球位置不触发声音。支持拖球及精细力度滑块，离开、失联、静音与切换页面会清理声源。

发射事件在权威 `MarbleGame.shoot` 接受操作后生成，携带位置、力度、序号和模拟时间。本机与联网复用事件，双方按画面显示时间播放一次，进入/重连不重播历史；无效操作不生成发射声。协议版本提升至 4。两段素材首次操作后异步加载，不阻塞场地显示。

## 以下为历史试听过程

用户已认可偏真实、克制的方案，并授权先制作试听。本轮交付离线声音，游戏接入需在音色试听后进行。

蓄力采用低音量、非音高型的指腹摩擦拟音，拖动时随力度略微增强，停止拖动淡出；不持续播放轰鸣，不将它声称为真实物理录音。发射采用短促的指腹弹击拟音，弱中强三档，区别于玻璃互撞的明亮长尾。两者均使用确定性噪声与阻尼振动合成，无外部录音。试听包含蓄力单独、发射单独与三档衔接。

后续接入约束：蓄力仅操作方可听；取消、停拖、退出时结束；发射与实际出手同步，双方可听，失败发射不播放。沿用现有总音量和静音。

交付使用 48kHz 单声道 PCM16 WAV，记录时长、峰值、RMS、文件哈希，检查无削波、非有限值或文件边缘突变。信号检查不能替代用户听感验收。

## 用户修订：弓箭风格 v2

用户指出合成指腹蓄力声不合适，要求直接参考拉弓与放箭。试听方向改为 SonoFxAudio 的 Bow_draw_slow01 与 Arrow_loose01 配套素材（CC BY 4.0）加工；本轮使用公开 HQ MP3 预览，来源、哈希、加工参数及署名见 assets/audio/gesture-bow-v2/。原“全部程序合成”的说明仅适用于 v1，不适用于本轮。v2 尚待试听，尚未接入；操作与时序约束沿用已认可方案。

## 用户选材：弹弓 A + 橡皮筋 C

用户明确选定 renne100 的 Slingshot（比较版 A）作为发射、Anthousai 的 rubber.wav（比较版 C）作为蓄力，并授权加工。加工试听位于 assets/audio/gesture-selected-ac/；A 裁掉出手前静音，C 提取两段拉伸并压低尖峰，包含快拉、慢拉、取消三种演示。来源均为 CC0 公开 HQ MP3 预览；本轮只确认选材和加工授权，加工后音色及运行时体验仍待验收。弓箭版及最初合成版保留为历史候选。

## 连续性与取消修订

用户指出上一加工版蓄力有反复绷紧/断开的感觉，并建议取消时拼接倒放声。候选改选 C 的连续 1.70–3.10 秒段，以峰值柔化、缓慢电平稳定和保音高变速形成单次后拉；取消倒放实际后拉的最近 0.5 秒并缩短、衰减，与后拉交叉淡化。试听位于 assets/audio/gesture-selected-ac-v2/。此项更新覆盖先前“取消仅淡出、没有独立音效”的设计；仍未接入游戏。原选 A 发射保持不变。

## 末段可听性与回弹感 v3

用户继续反馈蓄力末段无声感及取消松开感不足。移除独立试听留白，蓄力有效段适度增益；取消延长为 0.65 秒，倒放最近片段并用变化重采样速度形成由高到低的音高变化、与蓄力相近的起音和随后衰减。此项覆盖 v2 取消的保音高变速设计。候选位于 assets/audio/gesture-selected-ac-v3/；数值检查通过，主观方向仍待试听。
