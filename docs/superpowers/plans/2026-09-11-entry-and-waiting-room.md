# 入场视角、转场与等待房间修复

- [x] 复现：未开局断线仍保留席位 30 秒，另一人看到单人房间，但重新用链接加入被 locked 拒绝。
- [x] 未开局断线/主动离开释放席位并清除离开者准备状态；正式开局仍保留断线重连席位。等待房间自动恢复时令牌失效可重新加入，需重新准备。
- [x] 全景与双方入场改为 50°，正常出手保留 58°；按新角度重新计算场地取景，俯仰平滑插值并在拖动时锁定。
- [x] 进入游戏使用原有实时场景的 480ms 位移缩放过渡，无白色遮罩或新画布；过程中暂停场地触摸，减少动态效果设置直接跳过，退出和尺寸改变清理动画。
- [x] 网络测试、视角测试、浏览器移动横竖屏、链接退出重入与入场动画验证。
- [x] 提交部署，记录公开功能验证结果。

本地验证：119 项测试、生产构建通过。浏览器验证手机横竖屏和桌面 50° 全景、同画布入场动画、创建/练习入口、动画清理和减少动态效果；触摸发球/取消与双人独立视角回归通过。两名真实客户端和浏览器覆盖未开局主动离开、关闭房主/访客页面、原链接重入及临时断线自动重新加入；正式对局保持原席位重连。

上线验证：公网七项冒烟检查通过。两个手机视口实际验证未开局主动离开后原链接重入、关闭访客页面重入、关闭房主页面重入，以及等待房间临时断网后自动恢复；新加入者重新准备后可正常开局。无页面错误，共享域名其他服务正常响应。
