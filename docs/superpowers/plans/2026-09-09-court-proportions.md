# 场地与弹珠比例调整

**目标：** 缩小弹珠、扩大有效场地、降低过大的随机土坡，保留真实碰撞与透视。

**方案：** 球半径 0.062→0.05m；场地半边长 1.5→1.65m（面积增加 21%）；随机主坡幅度 0.15–0.23→0.065–0.10m。横向布局统一放大 1.1 倍，地面细粒和石块自身尺寸保留，坡体更宽缓。院落和玻璃反射平面共用横向比例，镜头按场地尺寸取景。地形与物理仍共用同一份网格，更新地图版本阻止旧版本混用。
