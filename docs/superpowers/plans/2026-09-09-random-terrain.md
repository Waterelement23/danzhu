# 每局随机物理地形实施计划

目标：权威对局生成一个不可变种子，每局刷新起伏、凹地、粗粒和石子；双方显示、碰撞、发球预测、焦散共用该局地形。

- [x] 添加确定性地形生成器及种子验证；保留种子 0 的旧资产作为历史测试参考。
- [x] 对局与快照携带种子，物理世界按实例接收地形，重赛换种子，重连保持原值。
- [x] 客户端只替换赛场，保留院落与相机；更新白线、预测、光学场和资源生命周期。
- [x] 增强起伏和土质色差，细化矿物颜色纹理，所有可见凸起沿用碰撞几何。
- [x] 验证同种子一致、不同种子变化、多房间隔离、碰撞高度/运动、两端同步与重赛/重连；构建及浏览器复核。

约束：不新增全局可变地形状态；远端客户端不能选择服务器种子；高差控制在可玩范围，入口清空障碍。普通轮换与缩圈不重新生成。保留既有胜负和延迟结算规则。
