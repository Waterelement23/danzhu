# 弹珠取消与无底板力度条

按用户要求移除白底力度卡片和虚拟白色起点；取消目标改为当前发射的真实弹珠，侧边竖向力度条显示百分比和松手提示。

- [x] 手势按实际弹珠的屏幕投影判定，包含高位发球，触摸半径至少 18px。球内起手先拉出再返回才取消，球外起手滑入即取消；8px 滞回，抬手检查最终坐标。
- [x] 无底板、无额外圆点；104×84px 力度组件优先位于球左侧，避免覆盖球和右侧玩家标签，靠边切换侧边。百分比位于竖条旁，保留取消/恢复时音效处理。
- [x] 单测、横竖屏原生触摸检查球内/球外起手、取消后恢复、弱发射、空白起点无标记及场地尺寸，生产构建。
- [x] 提交推送，部署，公网双人检查与部署记录。

验证：111 项测试、生产构建通过。390×844 和 844×390 浏览器原生触摸均完成 3 次出手；覆盖空白起手滑回真实球身取消、球身起手取消、球身轻拉发球、取消恢复、最终抬手坐标、双指和系统取消。确认力度条无背景、纵向显示且不覆盖当前球；无额外圆点，画布尺寸和渲染预算不变。未做真机手指遮挡测量。
