# 发球线点选实施计划

用户已批准：移除发球滑条；轻点发球线附近选位置，场地拖动继续瞄准，默认中间且不增加确认步骤。当前 worktree 顺序实施。

- [ ] 新增 `serve-selection.ts`，以投影后的地面线段计算点选位置，端点附近吸附至合法端点，远离线段返回空值。记录手势最大移动量，超过 5px 后即使回原点也不作为点选。先用 `tests/serve-selection.test.ts` 验证。
- [ ] 新增 `serve-line.ts`，用轻量 SVG 标出实际可用发球线、短刻度及当前位置，点选与显示使用同一份投影。只在可操作的入场回合显示；沿真实地面高度投影，不额外引入渲染通道。
- [ ] `scene.ts` 在按下时记录候选位置，抬手后才选择。拖动锁定原发球位置，取消/双指/离开回合清空候选；更新弹珠预览与高度投影，并回调 `main.ts` 同步最终发球参数。
- [ ] `main.ts` 和 `style.css` 移除滑条及相关样式；保留等待房间的邀请/准备浮层。首次提示改为“点发球线选位置，拖动场地发射”，正常回合沿用拖动提示；发球提示独立于旧版引导记录。
- [ ] 单元测试、生产构建与浏览器验证：横竖屏、左右端点、线外轻点、拖动不改位置、拖回取消不变位置、双指取消、后手入场、出手后的实际物理位置一致；正常回合不再可点选。更新既有手机回归脚本，执行真实联网回归。
- [ ] 推送并部署，检查公网两端点选发球、资源/房间服务，记录部署及回滚镜像。
