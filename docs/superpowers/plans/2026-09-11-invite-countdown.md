# 邀请入口精简与出手倒计时

按用户要求删除 8 位房间码输入入口，以分享链接加入；最后 10 秒以中央数字及音效提醒。

- [x] 删除表单、事件及样式，链接自动入房和恢复连接保留；无效邀请给出链接提示。
- [x] 当前操作者最后 10 至 1 秒显示中央无底板数字，最后 3 秒强调；不拦截触摸。出手、等待、结算、离开或隐藏页面收起。
- [x] Web Audio 短音共用主音量和静音；同回合同秒不重复，后台或不可操作期间消费秒数，恢复不补播。
- [x] 单测、构建、桌面/手机与真实双人邀请验证，检查声音次数和清理。
- [x] 提交部署，公网检查与部署记录。

本地验证：114 项测试和生产构建通过。手机与桌面确认倒计时中央位置、透明背景、不拦截触摸，实测提示音输出非零，同秒去重、静音/解除静音、跳秒不补播、出手清理通过。双浏览器链接入房、准备、发球、再战、断线结算以及同席重连和取消重连回归通过。未对实际 iPhone 扬声器音量作测量。

上线验证：公网七项冒烟检查通过。两名手机视口玩家通过邀请链接进入同一房间，实际等待到最后十秒，确认仅当前操作者显示中央数字并播放提示音，对手端保持安静；出手后提醒消失，双方后续发球和独立视角正常。无页面错误，共享域名其他服务仍正常响应。
