# 干土地面 · 落地与滚动音效试样

用户已认可土地落地剪辑，并指出砂砾原声具有滚动感，上一版短峰值切片丢失了连贯性。本轮保留土地落地文件，重新制作完整运动段和循环试听；尚未接入游戏。原录音为小石子落土和砂砾扰动，不标作真实玻璃珠录音。

## 最新验收：砂砾录音不适合作为滚动声

用户调大音量试听后，确认变化拼接版本仍夹杂沙子落地撞击，与玻璃珠在土地上的滚动有差别。所有 `earth-roll-*` 文件均停止作为滚动候选，仅保留试验记录；不接入游戏。土地落地剪辑继续保留。新素材搜索见上级目录 `dirt-sand-candidates.md`。

## 历史修订：打散固定循环

用户已指出 2.31 秒固定循环有明显重复感。当时的试听为 `earth-roll-varied-audition.wav`：12 秒连续运动，使用约 0.72–1.12 秒的原声长片段，变化截取位置和长度，用 90–150ms 等功率交叉渐变连接。保留段内微小声音和强弱，不变调、不滤波、不降噪、不做动态压缩。相邻片段避开相近的源起点。

固定循环版本已经被用户否定，仅保留作对比。若接入游戏，应实时选择后续片段，不循环这份 12 秒试听文件。固定随机种子仅用于复现此次试样。素材总长仍只有约 2.57 秒，打散时间顺序不等于增加新录音，熟悉的颗粒事件仍可能被识别，后续用户已否定其作为滚动声的听感。

验证：12 个既有 WAV（含已认可的落地声）字节不变。新文件为 12 秒单声道 48 kHz PCM16，无削波，16 个长片段衔接无空隙。旧 2.31 秒周期处波形相关性由约 0.9998 降至约 -0.0033，仅证明消除了原来的精确周期，不等于主观重复感完全消失。

## 前两轮试听与记录

- `earth-impact-audition.wav`：3 颗独立落地冲击，各播放两次，间隔 0.55 秒静音。用于确认起音、尾音和强弱，不是游戏中固定播放的弹跳序列。
- `earth-roll-natural.wav`：保留完整 2.571 秒砂砾原声，包括细小连接声音和自然衰减；原始音量，仅 6ms 淡入、15ms 淡出。
- `earth-roll-loop-audition.wav`：连续播放 3 次完整运动循环，约 6.93 秒，没有插入静音。用于听重复感和接缝。
- `earth-grit-audition.wav`：上一版短峰值切片，只保留作可选颗粒撞击细节，不作为滚动音效。

## 滚动修订依据

上一版仅依据短时波形峰值作了过度切割，把原录音中连接颗粒事件的低幅细节和节奏删掉，导致试听变成孤立撞击。用户实际试听认可原录音的滚动感，因此不再以“波形存在峰值”为理由否定它。

新版滚动文件从未经过高通的砂砾原录音重新解码，保持原始音量，不做降噪、变调、压缩或削除峰值。自然版保留全长。`earth-roll-loop.wav` 取 0.04–2.43 秒，首尾做 80ms 线性交叉渐变，得到 2.31 秒循环；循环时间原点移至原录音 0.12 秒，其余内部事件顺序和连接细节保留。

用户后续试听确认固定循环的重复感明显，本轮已按上文方案重新制作。
