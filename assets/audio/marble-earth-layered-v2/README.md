# 叠加滚动声 · 减弱落砂撞击

用户认为上一轮混合方向改善明显，但落砂撞击过于突出。本轮使用上一轮较轻落砂混合作为基准，只进一步衰减落砂层中的较强事件。滚动底声字节不变，不变调、不循环、不补偿放大。

- `earth-roll-soft-sand.wav`：新版本，2.14 秒。
- `earth-roll-soft-sand-comparison.wav`：上一轮轻落砂版 → 新版，间隔 0.8 秒，总长 5.63 秒。
- `sand-layer-before/after.wav`：单独砂层的诊断输出，不作为独立滚动音效使用。

处理使用居中 10ms RMS 包络，在包络第 65 百分位以上逐渐衰减，指数 0.85，最大允许衰减 18dB，增益曲线平滑 5ms。较安静部分不增加音量，也不切除事件。砂层峰值降低约 7.6dB、整体 RMS 降约 3.1dB，因此相较于整层简单调小，更集中地处理突出撞击。强事件并未完全消除，用户认为新版听感可接受。

来源和前置滤镜沿用上一轮，详见 manifest.json。运行 `python scripts/mix-earth-rolling-v2.py /Users/tt/code/other/danzhu` 可复现，需 ffmpeg 与 numpy。

## 已确认音色与运行时限制

用户确认新版听感可接受，但指出原录音是由远而近再远的经过过程，加工版本也保留了这段变化。当前只通过音色评估，未通过持续滚动播放验收。所有当前输出禁止直接整段循环；循环衔接平滑也不能消除反复接近、远离的听觉运动。

接入前需另制相对稳定、固定距离视角的滚动纹理。优先尝试从原素材中选取距离变化较小的连续段，适度校正缓慢电平变化；避免放大安静尾部噪声、抹平真实接触强弱。均衡响度不能自动移除已录入的声像、频谱或混响变化；如无法提取足够自然的稳定段，需要补录固定麦克风距离的素材。不能通过随机截取整段或单纯首尾淡化来宣称问题解决。

后续由游戏依据画面中球与听者的世界坐标控制距离衰减和左右声像，依据球速、接触状态、地面材质控制滚动强弱。离地或停止滚动时平滑停止滚动层，落地/弹珠碰撞独立触发。

验收应包括固定距离匀速持续播放 15–30 秒（不能周期性忽远忽近）、横向移动、远近移动、减速停止、离地，以及检查音画同步和拼接重复感。当前未实施运行时接入，也未生成合格的持续播放素材。
