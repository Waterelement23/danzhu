# 蓄力与发射拟音试听

当前为离线候选，未接入游戏，尚待用户听感验收。所有声音均为程序合成，不是手指弹珠的实录，也未采样此前玻璃互撞、滚动或土地录音。

## 试听顺序

1. `aim-charge-audition.wav`（6 秒）：0.35–1.55 秒轻柔后拉；2.20–3.60 秒增加力度；4.20–5.30 秒逐渐减力后取消。停拖处有安静间隔，模拟操作停止即淡出。是交互演示，不能整段循环。
2. `release-audition.wav`（3.2 秒）：0.40、1.35、2.30 秒分别为轻、中、重三次发射。
3. `gesture-audition.wav`（10 秒）：弱、中、强三组“拖动蓄力—松手出手”，发射时刻为 1.30、4.60、8.50 秒。拖动尾部与弹击重叠 35ms。

`release-01/02/03.wav` 是上述三段独立弹击，各 140ms。三个试听文件保留同一混音关系，不分别归一化到最大响度。

## 声音设计

蓄力：160Hz 附近高通形状、1.7kHz 四阶低通形状的随机相位噪声，叠加低深度不规则摩擦变化。幅度随演示力度变化，35ms 淡入、55ms 淡出，无规律脉冲或音高爬升。

发射：短噪声压力脉冲、快速阻尼的 330/720Hz 振动及少量摩擦尾音；意图模拟指腹弹击的短钝触感，没有玻璃长尾，也不使用夸张的飞行呼啸。各档种子和幅度固定，便于复现和比较。

## 复现与检查

运行 `python scripts/build-gesture-audio.py`（依赖 NumPy）。输出 48kHz、单声道、PCM16 WAV。validation.json 保存每个文件的长度、RMS、峰值、边缘采样与 SHA256。

6 个文件重新解码检查通过，峰值最高 -11.6dBFS，无削波，首尾采样为零。数值检查不能确认主观真实性；需由用户试听选择音色和相对响度。
