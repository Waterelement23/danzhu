# 瓷砖地面 · 弹珠音效候选

来源：用户提供的 `marble_tile_drop_and_rolling.wav`，原文件位于项目主目录，仅改名，音频内容未修改。来源网站及授权信息未随文件提供。用户试听判断弹跳和滚动均偏瓷砖质感，因此归档为未来瓷砖场地候选，不用于当前干土地面。这是听感归类，并非已证实原录音发生在瓷砖上。尚未接入游戏或发布。

原文件为 96 kHz 双声道浮点 WAV，约 4.639 秒。波形前段有多次分立冲击，后段为持续低强度信号，支持“弹跳后滚动”的结构判断；当前处理环境无法听辨，不能据此确认材质、背景杂音或最终循环听感。

## 文件

- `marble-tile-bounce-01/02/03.wav`：前三次独立冲击，分别取原音频 0.237–0.414、0.428–0.582、0.594–0.731 秒。使用同一增益保留相对强弱。
- `marble-tile-bounce-audition.wav`：三段冲击之间插入静音的试听合集。游戏应按每次实际碰撞触发独立片段，不能播放这个固定合集来代替物理时序。
- `marble-tile-rolling-tail.wav`：原录音 2.02–4.16 秒尾段候选，避开前段大冲击与约 4.32 秒额外波动。
- `marble-tile-rolling-loop.wav`：对该尾段做 120ms 头尾交叉渐变，得到 2.02 秒循环候选。没有依赖强力降噪来重塑材质。
- `marble-tile-rolling-audition.wav`：循环三次的 6.06 秒试听版本；用于听接缝、重复节奏和底噪，游戏循环应使用 `marble-tile-rolling-loop.wav`。
- `manifest.json`：切点、增益、时长与输出峰值。

所有输出为 48 kHz、单声道、16-bit PCM WAV，便于后续由游戏控制空间声像。先在浮点域混合声道、80 Hz 高通，再降低冲击增益留出峰值空间，避免直接转整数时截断源浮点超过 0 dBFS 的样本。单次冲击做 1ms 淡入和 18ms 淡出；滚动尾段仅温和增益，不归一化到冲击响度。

## 试听重点

1. 独立冲击是否保留了完整的起音和自然尾音，有无切断或混入下一次撞击。
2. 后段究竟是弹珠滚动还是包含明显环境底噪；循环是否有可辨重复或周期性起伏。
3. 实际材质是否符合土地。若来源为硬地录音，应作为硬地候选；单纯降低高频不能凭空获得真实砂土摩擦质感。

可复现命令（Python 需 numpy，系统需 ffmpeg）：

```sh
python scripts/extract-marble-audio.py /path/to/marble_tile_drop_and_rolling.wav
```

数值校验：7 个输出均可解码、单声道 48 kHz、无满幅削波；这不等于已经完成主观音质验收。
