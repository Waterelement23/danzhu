# 土地滚动循环与碰石声候选

用户授权用弹珠互撞声加工碰石声，并制作多个可循环滚动版本供选择。2026-09-10 用户已通过本轮离线听感验收：滚动声自然，未听出机械重复或忽远忽近；碰石声像碰石头。三版滚动候选均保留，用户未指定优先版本；尚未接入游戏。

## 滚动 A / B / C

| 文件 | 方向 | 长度 |
| --- | --- | --- |
| `earth-loop-a-smooth.wav` | 平滑土面：滚动底声为主，砂层较轻 | 8 秒 |
| `earth-loop-b-fine-sand.wav` | 细砂土面：较明显但柔和的砂层 | 8 秒 |
| `earth-loop-c-grainy.wav` | 颗粒稍明显：砂层比例增加，短时纹理变化稍多 | 8 秒 |

对应 `-audition.wav` 为原样连续重复三次的 24 秒试听，第 8、16 秒是循环边界。仅整份试听最外侧淡入淡出，内部循环接缝没有额外静音或遮盖处理。三版 RMS 均约 -33dBFS，便于比较，不代表主观等响度。

### 如何处理自带的远近变化

使用此前认可的 `marble-earth-layered-v2` 滚动底声和削弱撞击后的砂层作为频谱参考，平均各时间窗的功率谱，再以随机相位重建周期纹理。**这是基于素材频谱的合成试样，不是保留完整原录音的拼接，也不是恢复出的真实土面录音。** 原时间顺序及其远近包络不参与生成；不会按原来的“远→近→远”顺序播放。

周期信号由完整 8 秒傅里叶频率网格生成，另外使用环形 RMS 平滑轻度稳定音量。砂层只有约 40ms 尺度、有限幅度的颗粒变化，没有人为添加秒级接近/远离曲线。具体随机种子、层级、截止频率和调制深度见 manifest.json。这个办法会改变原来的微观细节，因此必须试听判断是否变成过于均匀的噪声或出现机械感。

所有有限循环最终都会重复。8 秒只是候选长度，不能据此宣称无限无重复；完整 24 秒试听用于检查节奏、纹理和接缝，选定后仍需在固定距离持续播放、实际减速、离地、停止和空间移动中验证。此前原始经过录音仍禁止直接循环。

## 玻璃珠碰石块

`marble-stone-01.wav` 至 `08.wav` 是 8 段约 200ms 的候选。`marble-stone-audition.wav` 按顺序各播一次，间隔 600ms。

来源为已认可的玻璃珠互撞片段，90Hz 高通、2.4kHz 宽带衰减 4dB、3.6kHz 低通；起音后 30ms 开始以 45ms 时间常数衰减尾音，共同降低 1dB，保留原相对强弱和音高。意图减少玻璃的亮感和延续响声，形成更短、更钝的接触感；这是设计近似，不能标作真实玻璃珠碰石录音。

署名：Two marbles colliding by D43thsilence — https://freesound.org/people/D43thsilence/sounds/755084/ — CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Modified: channel selection, resampling, trimming, EQ, gain and tail damping.

砂层来源 Sheyvan / Freesound 569738，CC0。原滚动源为用户提供的硬地录音，来源网站和许可未随文件提供，本轮仅本地试听。各层来源与哈希保存在 manifest.json，原录音和此前认可片段均不变。

## 重现与验证

运行 `python scripts/build-game-audio-candidates.py`，依赖 numpy 与 ffmpeg。

已验证 15 个 WAV 的格式、时长、无削波和文件哈希；3 个循环半秒窗口 RMS 范围分别约 0.40/0.41/0.69dB，循环边界采样差落在内部正常差分范围内。试听中间循环与原循环逐样本相同。数值见 validation.json；这些检查不能替代主观听感和真实游戏验收。

## 接入前状态

本轮听感认可已记录在 manifest.json 和 validation.json。`auditionApproved: true` 表示离线试听通过；`runtimeReady: false` 保留，用于区分尚未完成的真实游戏接触触发、速度控制、空间声像、淡入淡出及混音验收。用户尚未从 A/B/C 中指定一个默认版本，不能将任一版本标为用户选定。
